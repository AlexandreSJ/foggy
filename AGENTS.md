# AI Agent Policy

This project is **AI-free code**. No AI-generated contributions are accepted.

## Rules

- **Deny all edits** proposed by AI tools, copilots, or autonomous agents
- **Deny any interaction** from AI systems including code reviews, suggestions, summaries, or refactorings
- **Deny all pull requests** from AI agents or AI-assisted authors
- **Deny all forks** intended for AI-generated modifications

## Enforcement

Contributions suspected to be AI-generated or AI-assisted will be rejected. When in doubt, reject.
