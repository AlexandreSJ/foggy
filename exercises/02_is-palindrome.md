[Go Back](README.md)

## Description

Given a string, determine if it is a palindrome.
- If string is empty, return error
- If string has spaces, ignore them
- If there are any uppercase letters, treat them as lowercase
- If there are any special characters, ignore them

## Testing Input

Given this input, the user should expect the following [Expected Output](#expected-output):

```md
racecar
foggy
rainy day
Do geese see God
No lemon, no melon
```

## Expected Output
```bash
true
false
false
true
true
```
